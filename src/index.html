Luanti NodeBox Studio

The modern, accessible, open-source 3D visual NodeBox Editor, Texture Studio, and Lua Code Generator for Luanti (formerly Minetest) game developers and mod creators.

Interactive 3D Visual Viewport

Design custom 3D voxel nodeboxes with precise sub-grid snapping (1/16th, 1/32nd, 1/64th). Includes Move, Rotate 90°, Scale, and Dimension gizmos, orthogonal and perspective camera modes, and live neighbor block simulation for connected, wallmounted, and leveled nodes.

6-Face Texture Studio & Pixel Painter

Map individual textures across all 6 Luanti cube faces (+Y, -Y, +X, -X, +Z, -Z). Paint pixels directly in 2D or paint onto 3D surfaces in real time with Pencil, Bucket Fill, Line, and Color Picker tools, complete with vertical sprite sheet animated frame previews.

Render Studio, Atmosphere & 3D Extrusion

Preview models in authentic Luanti Day, Sunset, and Night cubic atmospheres with 3D celestial sun, moon, and voxel starfields. Transform 2D pixel art into real 3D extruded voxel relief, and export ultra-HD 4K screenshots or 512×512 transparent inventory icon PNGs.

Lua Code Generator & Live Importer

Generate clean, standard core.register_node definitions in 16ths fractions, decimals, or grid integers. Import existing Lua mod definitions directly by pasting snippets with instant coordinate parsing and automatic texture extraction.
